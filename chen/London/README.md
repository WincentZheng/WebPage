# 🇬🇧 倫敦 2026 自由行 - 多人行動伴旅系統 (London Travel Web App)

專為 2026/10/04 ~ 2026/10/15 倫敦 12 天 10 夜多人自由行打造的手機專用伴旅網頁。收錄完整每日行程、帕丁頓住宿、景點導航、多人智慧分帳結算（Splitwise 演算法）、行前裝備打卡與購物代購願望清單。

---

## 🌟 核心特色

1. **📱 手機優先瀏覽體驗 (Mobile-First Web App)**
   - 專為單手操作設計，支援 iPhone Safari / Android Chrome「加入主畫面」全螢幕操作。
   - 雙時區即時時鐘（倫敦 GMT vs 台北 TST），不怕算錯時差。
   - 離線支援（LocalStorage 本地隨身儲存），地鐵無訊號亦能查看行程。

2. **📅 完整 12 天行程與一鍵導航**
   - 涵蓋大英博物館、哈利波特影城、溫莎城堡、牛津、劍橋康河撐篙、格林威治本初子午線、白金漢宮衛兵交接等精選行程。
   - 上午/下午/晚上/餐飲分時卡片，每個景點直連 Google Maps 導航。

3. **💰 多人智慧分帳與債務消除 (Splitwise 算盤)**
   - 支援英鎊 (£) 與台幣 (NT$) 雙幣別輸入與自訂即時匯率。
   - 多人代墊、自選分攤對象。
   - 自動以最佳路徑消除多角債務（誰該轉給誰多少錢），支援「一鍵複製結算清單到 LINE」。

4. **🏨 住宿與生活急難指南**
   - 帕丁頓 150 Sussex Gardens 住宿導航，一鍵複製英式郵遞區號 `W2 1TU` 與地址（叫車/Uber 必備）。
   - 駐英國台北代表處 24 小時急難救助電話、999、101 直撥連結。
   - 牡蠣卡 (Oyster) 與感應信用卡 (Contactless) Daily Cap 每日扣款上限說明。

## 🚀 GitHub Pages 發布步驟

本專案為**純靜態網站（Pure Static Web App）**，無需安裝 Node.js 或任何建置編譯步驟，直接上傳即可使用：

1. 在 GitHub 上建立一個新的公開儲存庫（Repository），例如取名為 `London`。
2. 將專案中的檔案（`index.html`、`css/`、`js/`、`.nojekyll`）上傳或 Push 至該儲存庫的 `main` 分支。
3. 進入儲存庫的 **Settings** ➔ 點選左側選單的 **Pages**。
4. 在 **Build and deployment** 下方的 **Branch** 選擇 `main` / `/(root)`，點擊 **Save**。
5. 等候 1~2 分鐘，即可獲得線上專屬網址：
   `https://<你的GitHub帳號>.github.io/London/`
